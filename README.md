# Heart Disease Predictor

This project is a Machine Learning based web application that predicts the likelihood of a person having heart disease based on various medical parameters like age, blood pressure, cholesterol levels, etc.

The model is trained on a heart disease dataset and provides quick predictions through an interactive web interface built with Streamlit.

---

## Tech Stack Used:
- Python
- Pandas
- NumPy
- Scikit-learn (ML Models)
- Streamlit (Web App)

---

## Features:
- Predicts risk of heart disease based on health details
- User-friendly interface using Streamlit
- Model trained using Logistic Regression and Random Forest
- Real-time prediction results
- Clean and responsive UI

---

## Dataset:
The dataset used (`heart_disease.csv`) contains patient medical records with features like:
- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol Level
- Maximum Heart Rate
- Fasting Blood Sugar
- Rest ECG
- Exercise Induced Angina
- ST Depression
- Target (0 = No Disease, 1 = Disease)
